# Audio Credits

All imported audio in this folder is licensed as Creative Commons Zero (CC0). Credit is not required, but the sources are recorded here so the project can track provenance.

## Kenney Audio Packs

Source: https://kenney.nl/assets?category=Audio

License: Creative Commons Zero (CC0), https://creativecommons.org/publicdomain/zero/1.0/

Imported packs:

- UI Audio: https://kenney.nl/assets/ui-audio
- Sci-fi Sounds: https://kenney.nl/assets/sci-fi-sounds
- Digital Audio: https://kenney.nl/assets/digital-audio
